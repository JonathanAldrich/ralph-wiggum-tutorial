Pac-Man

A playable, single-level Pac-Man built on the same React Islands stack as the Hello demo. Unlike Hello, this page showcases a canvas render loop, animation, and richer interactive state — all client-side, with no backend persistence.

  • Pause / resume: P
  • On touch devices, use the on-screen D-pad below the board.
